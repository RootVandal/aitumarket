# AituMarket

Концепт сервиса доставки продуктов для Казахстана: каталог, корзина, оформление заказа и живой трекинг курьера. Интерфейс на двух языках — русском и казахском.

Без фреймворков, сборки и зависимостей: чистые HTML, CSS и JS. Открывается двойным кликом по `index.html` или с любого статического хостинга (GitHub Pages).

## Что внутри

- **5 вкладок** — Главная, Каталог, Корзина, Заказы, Профиль. Роутинг через hash, кнопка «назад» работает.
- **RU / ҚАЗ** — переключение всего интерфейса, включая названия товаров, описания, регионы и даты. Казахские даты форматируются вручную: во многих браузерах нет локали `kk-KZ`.
- **45 товаров с собственными иллюстрациями** — каждая нарисована SVG-примитивами в едином стиле, без стоковых фото и эмодзи.
- **Казахский контекст** — тандыр нан, қымыз, шұбат, құрт, жент, кызылординский рис, сезон алматинского апорта. Есть набор «Собрать дастархан» в один тап.
- **Корзина** — прогресс до бесплатной доставки, выбор слота, промокод `AITU10`, «оставить у двери». Состояние хранится в `localStorage`.
- **Трекинг заказа** — стилизованная карта с горами на горизонте; курьер едет по маршруту в реальном времени, статусы меняются сами.
- **Адаптивность** — на телефоне нижний таб-бар, bottom-sheet товара со свайпом вниз и мини-корзина. На десктопе боковая навигация, модальное окно товара и постоянная колонка корзины (от 1280px).
- **Детали** — анимация «товар летит в корзину», обновление карточек без перерисовки (горизонтальные ленты сохраняют прокрутку), поддержка `prefers-reduced-motion`, focus-стили для клавиатуры.

## Дизайн

Тёплая «бумага» с лёгким зерном, глубокий лесной зелёный, абрикосовый акцент. Вместо градиентов и неона — орнамент қошқар мүйіз (бараньи рога): он есть в логотипе, на этикетках товаров, баннерах и бонусной карте. Шрифты: Unbounded (заголовки) и Onest (текст), оба с казахской кириллицей.

## Структура

```
index.html     оболочка
styles.css     дизайн-система и адаптивная раскладка
js/data.js     каталог, регионы, хозяйства, словарь RU/ҚАЗ
js/art.js      SVG-иллюстрации товаров
js/app.js      состояние, роутинг, экраны, корзина, трекинг
```

## Запуск

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000.
